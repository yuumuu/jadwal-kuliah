📌 Overview & Arsitektur

JadKul adalah aplikasi Single Page Application (SPA) berbasis web statis untuk mengelola dan menampilkan jadwal kuliah serta kalender akademik Prodi Teknologi Informasi Universitas Muhammadiyah Yogyakarta (UMY).

Aplikasi ini dirancang khusus untuk berjalan langsung melalui GitHub Pages tanpa memerlukan server backend atau database relasional tambahan.

Prinsip Desain Utama:

⚡ Zero Dependencies

Murni HTML5, CSS3, dan Vanilla JS (ES2020+).

📱 Mobile-First UX

Antarmuka responsif dan ramah perangkat seluler.

🗂️ JSON Data Driven

Seluruh jadwal disimpan dalam format file JSON terpisah.

📱 Panduan Pengguna

Berikut adalah fitur-fitur utama yang dapat dimanfaatkan pengguna saat membuka aplikasi:

1. Pemilihan Semester & Kelas Utama

Saat pertama kali membuka situs, pop-up konfigurasi akan muncul. Anda dapat memilih Semester Aktif atau melihat Arsip Semester lama, lalu menentukan Kelas Utama Anda (misal: Kelas A, B, C) untuk memberikan sorotan visual otomatis pada setiap sesi kuliah.

2. Mode Tampilan (Table, Grid, List, Timeline)

Gunakan tombol pemilih mode tampilan di kanan atas filter card untuk mengganti tampilan jadwal sesuai preferensi Anda.

3. Filter Cepat "Hari Ini" & Pencarian Instant

Klik chip Hari Ini untuk langsung menampilkan sesi kuliah hari ini, atau ketik nama dosen, ruang (contoh: F4.001), atau kode mata kuliah pada kotak pencarian.

4. Salin Ringkasan untuk Grup WhatsApp / Telegram

Klik tombol Salin Ringkasan di pojok kanan bawah toolbar untuk menyalin ringkasan jadwal dalam format teks rapi yang siap dibagikan ke grup obrolan.

🤝 Panduan Kontribusi (Fork & PR)

Siapa saja dapat berkontribusi menambah data jadwal semester baru atau memperbaiki informasi dosen dan ruangan. Ikuti 5 langkah berikut:

Langkah 1
Fork Repository

Buka repository GitHub github.com/yuumuu/jadwal-kuliah lalu klik tombol Fork di kanan atas.

Langkah 2
Clone ke Perangkat Lokal
git clone https://github.com/USERNAME_ANDA/jadwal-kuliah.git
cd jadwal-kuliah
Langkah 3
Tambah File Detail JSON di Folder data/

Salin data/template.json dan buat file baru, contoh: data/ti-s3-gasal-2026.json. Isi data sesi kuliah, jam, ruang, dosen, dan libur nasional.

Langkah 4
Daftarkan di Index Master (data/jadwal.json)

Buka data/jadwal.json dan tambahkan objek semester baru:

{
  "id": "ti-s3-gasal-2026",
  "label": "Semester 3",
  "period": "Gasal",
  "academicYear": "2026/2027",
  "program": "TI",
  "semester": 3,
  "status": "active",
  "active": true,
  "startDate": "2026-09-01",
  "endDate": "2027-01-15",
  "file": "data/ti-s3-gasal-2026.json"
}
Langkah 5
Commit, Push, & Buat Pull Request
git add .
git commit -m "feat: tambah data jadwal Semester 3 Gasal 2026/2027"
git push origin main

Buka repo asal lalu klik tombol Compare & Pull Request.

📄 Spesifikasi Skema JSON

Struktur data jadwal dibagi menjadi 2 jenis file:

1. Index Master (data/jadwal.json)

Berisi daftar metadata seluruh semester yang terdaftar di aplikasi:

{
  "semesters": [
    {
      "id": "ti-s5-gasal-2026",          // Unique ID (snake_case)
      "label": "Semester 5",          // Label nama yang tampil
      "period": "Gasal",              // Gasal / Genap
      "academicYear": "2026/2027",    // Tahun ajaran
      "program": "TI",                // Program Studi (TI / AI)
      "semester": 5,                  // Angka semester
      "status": "active",             // "active" atau "archived"
      "active": true,                 // boolean status
      "startDate": "2026-09-01",      // YYYY-MM-DD
      "endDate": "2027-01-15",
      "file": "data/ti-s5-gasal-2026.json" // Path file detail
    }
  ]
}

2. Detail Semester (data/ti-sX-gasal-YYYY.json)

Berisi perincian sesi perkuliahan per hari, libur nasional, dan agenda penting:

{
  "subjectColors": {
    "TI501": "#3b82f6",
    "TI502": "#8b5cf6"
  },
  "holidays": [
    { "date": "2026-01-01", "name": "Tahun Baru Masehi" }
  ],
  "importantDates": [
    { "date": "2026-09-07", "name": "Awal Perkuliahan" }
  ],
  "schedules": {
    "Senin": [
      {
        "kode": "TI506",
        "matkul": "Manajemen Proyek",
        "kelas": "D",                 // Bisa multi-kelas: "D,E,F"
        "jam": "08.50-11.30",
        "ruang": "F6.102",
        "dosen": "HQ/WS"
      }
    ]
  }
}
